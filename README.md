# COMPOSITE SPEED® — Carbon Fibre Seatpost

White Custo-style product site with:
- Hero product photography (bike / seatpost in situ)
- GSAP ScrollTrigger explode scrub under the hero (assembled → exploded)
- Framer Motion loader + UI motion
- Engineering-focused copy for cyclists

## Run

```bash
npm install
npm run dev
```

## Build / deploy

```bash
npm run build
npm run preview
```

Live: https://stria-carbon-rod.vercel.app
